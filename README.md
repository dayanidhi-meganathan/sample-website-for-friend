# Global Expertise Limited — website

One-page website for Global Expertise Limited, a London studio for PR, media relations and personal branding.

## Files

- `index.html` — the whole site (HTML, CSS and a few lines of JS for the mobile menu)
- `assets/` — logo mark, full logo, favicon and founder portraits

No build step. Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Netlify, Vercel).

## Before going live

- Add a company email address and phone number in the Contact section (marked with a comment in `index.html`).
- Confirm the FAQ answers and the "How we work" steps with the founders.
- Replace `assets/logo-mark.png` and `assets/logo-full.png` with the original high-resolution logo files.
- Confirm the founders are happy with the portraits used.
